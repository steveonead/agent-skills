# 任務格式模板

本地 Markdown 中每個垂直 slice 任務使用以下格式。

---

## Task：[完成後使用者可看到或驗證的行為]

**描述：** 描述此 vertical slice 的端到端行為，不要逐層列舉實作細節（❌ 建 schema → 建 API → 建 UI）。

**驗收條件：**
- [ ] [具體可測試的條件]
- [ ] [具體可測試的條件]
- [ ] [具體可測試的條件]

**Blocked by：** 本地草稿填任務標題或「無」。推 GitHub 後改為 #<issue-number>

**Size：** XS / S / M / L（草稿可暫標 XL 表示需再拆，最終確認後不可有 XL）

## ✅ Checkpoint：[里程碑名稱]

確認以下條件後再繼續：
- [ ] [可驗證的條件]
- [ ] [可驗證的條件]
